The vocabulary for federated ship design.

VsML is an open ontology vocabulary bridging OCX Schema, SFI Index System, and W3C standards — exposing rich semantic relationships across maritime vessel data.

Federated ontologies

VsML bridges five external vocabularies

OCX
OCX Schema
Structural and dimensional vessel data — lengths, breadths, draughts, hydrostatic coefficients
SFI
SFI Index System
Ship systems reference designators — propulsion, navigation, safety, deck equipment
ORG
W3C Organization
Organizational concepts — owner, faculty, classification society, port of registry
PROV
PROV-O
Provenance and documentation — evidenced by drawings, specifications, arrangements
OM
Units of Measure
Measurements and units — hasValue, hasUnit for quantitative vessel parameters
